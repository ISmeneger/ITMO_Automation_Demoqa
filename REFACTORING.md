# Рефакторинг учебного проекта ИТМО

Сохранены Page Object структура, отдельные Components и домашние задания. Учебные примеры markers/skip отделены от активных UI-проверок.

## Изменения

- Исправлены импорт Keys, URL формы, чтение input.value, CSS-имена и прокрутка к заданному элементу.
- Убраны ненужные зависимости и бинарный ChromeDriver; используется Selenium Manager.
- React-поля очищаются клавиатурой с событием ввода.
- Явные ожидания заменяют фиксированные паузы; циклы ограничены.
- Браузер создаётся отдельно для каждого UI-сценария.
- Обновлены локаторы для новой версии DemoQA, viewport проверяется семантически, footer учитывает текущий год.
- CRUD таблицы проверяется по данным записей, пагинация — по реальным страницам.
- Поддерживаемый поиск заменил историческую сортировку в активном наборе.
- Подтверждённые дефекты Close и восстановления удалённых записей отмечены строгим xfail с ограничением типа ошибки.
- Обычные UI-падения сохраняют screenshot, HTML и URL.
